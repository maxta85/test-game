## How to see this yourself

```bash
python3 ~/kilo-fleet/fleet2.py board            # snapshot
python3 ~/kilo-fleet/fleet2.py follow --all      # live stream, Ctrl-C to stop
python3 ~/kilo-fleet/fleet2.py log w3 30         # last 30 events for one agent
python3 ~/kilo-fleet/fleet2.py verdict w3        # its acceptance result
```

Logs are JSONL in `~/kilo-fleet/logs/<worker>.jsonl` — one JSON object per
agent event, greppable.
